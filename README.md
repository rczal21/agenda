# agenda/contact list
Contact list in C

Agenda de contatos em C


English 

This program is designed to create and maintain a digital contact list. You can store up to 50 contacts, including each person's name, phone number, and address. The program also allows you to view the full list, search for specific contacts, remove entries, and update contact information. All data is saved in a file named "agenda.txt," which is generated the first time you run the program.
This was my first personal project developed entirely on my own, and I really enjoyed working on it! If you have any questions or come across any errors, please let me know!

Português

Esse programa tem como objetivo de criar e ter uma agenda de contatos de forma digital. Nela, é possível ter na agenda até 50 contatos, contendo nome, telefone e endereço de cada um. É possível também visualizar a lista completa, buscar algum contato, remover algum contato e alterar os dados de algum contato. Tudo isso é salvo em um arquivo chamado "agenda.txt", que é gerado quando se roda o programa pela primeira vez. 
Esse foi meu primeiro projeto pessoal desenvolvido totalmente sozinha e achei muito divertido de fazer. Se tiver alguma dúvida ou erro, fale comigo!
